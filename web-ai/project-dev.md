# 人工智能代码编辑器 开发项目
## 是什么？
- 传统代码编辑器：前端人员开发代码的编辑器，如vscode,webstorm等
- 人工智能代码编辑器：基于人工智能体的代码生成能力，直接生成项目代码
  - 如Cursor
  - 如Trae

## 为什么需要人工智能代码编辑器？
- 解决传统编辑器，必须手写代码，比较慢的痛点；
- AI编辑器，根据原型UI，需求，接口文档迅速生成代码，几分钟甚至几秒就能开发完成一个页面，速度秒杀人工手写代码。
- 让开发人员专注需求，实现交给AI大模型，代码由编辑器自动生成
- 快速排查并修复报错：将报错复制或截图给AI，即可修复报错

## 怎么做？
- 基于项目和需求，让AI进行技术选型
- 基于技术选型，让AI创建项目
- 把页面原型图或者UI图，交给AI，写入描述，让AI生成 ** 页面布局 ** 代码
- 业务页面怎么开发？
  - 把用户管理菜单页的UI图交给AI，写入描述，把需求+接口地址，方法，请求参数，响应参数，给到智能体，让他直接生成页面代码
- 出现报错怎么办？
  - 复制或截图报错，交给AI，让它解决即可

## cursor VS Codex
1. cursor是对话型智能体，我是主驾驶，我指导模型帮我写代码，有限跨多文件上下文，适合1-8个文件写代码增强，多了容易漏；
2. Codex相当于你是产品经理，模型是你的外包程序员
   - cursor比codex快，但codex是任务型Agent智能体，擅长多文件上下文，比如20+个文件，尤其擅长整个项目，整个模块的文件一起改，一起修bug。
