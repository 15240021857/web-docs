# 怎么记笔记

## 什么时候记笔记

1. 时机：**边学边记**，学完再记，懒得记，记忆模糊
2. 记什么：**记骨架**， 强制自己**提炼重点**
3. 看完再回忆：**能回忆起来才是自己的**

```text
标题：NestJS Controller

- 干嘛用的：接收请求，调Service，返回响应
- 怎么写：@Controller('prefix') + @Get() @Post()
- 跟Express区别：不用app.get()，用装饰器
- 我踩的坑：路径前缀忘了加，404了半天
```

## 什么时机写技术博客

1. 时机：**刚做完一个功能/踩完一个坑立即写**，项目做完懒得写了
2. 理由：刚做完记忆最鲜活

时机表：
| 时机 | 写什么
