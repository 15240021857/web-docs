# 自测

- 是什么？
自测是指在功能开发完成后，由开发人员或测试人员对功能进行测试，以验证功能是否符合预期。

- 为什么要做？解决什么问题？
  - 自测可以提前发现功能中的错误和边界问题，及时修复，避免在生产环境中出现错误，代价更大。
  - 自测可以确保功能的稳定性和可靠性，提高用户满意度。

## 单元测试
### 是什么
- 单元测试是指对代码中的独立单元（测试用例）进行测试，以验证其是否符合预期。
- 可配合ci/CD工具，自动执行单元测试，确保代码质量。
### 哪些框架
- vue的单元测试：vitest
- react的单元测试：jest
## e2e测试
核心功能，需要在真实环境中测试，确保功能正常运行。
- 端侧测试：cypress
- 客户端测试：playwright
