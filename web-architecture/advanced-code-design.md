# 高级程序设计了解

## 是什么
高级程序设计 ≠ 高级前端 || 高级后端

> 它教你怎么把代码写的更聪明、组织更清晰、性能更高

- **初级程序设计**：教你如何写字、造句、写段落
- **高级程序设计**：教你写小说、写议论文、写架构——怎么让文章写得结构清晰、逻辑严密、还能改的动

<!-- > 他不是教你更高级的语言，而是教你用更高级的方式思考、设计和写程序 -->

> 它不绑定前端，也不绑定后端，而是让你用任何语言都能写出“专业级代码”，它是底子课。

## 跟前后端的关系
- 前端：写复杂组件、状态管理、性能优化、工程化、架构设计……
- 后端：接口设计、数据库优化、系统架构、高并发……


## 它到底在讲什么？
### 语言特性：代码怎么长的高级
- 比如泛型、异常处理、Lambda表达式、反射、注解……
- 这些语法不是炫技，而是 少写重复代码、提前防bug、搭积木而不是“糊泥巴”

类比：初级用**锤子钉钉子**，高级用**电动工具、标准零件**

### 算法与数据结构：程序怎么想的高级
- 不只讲冒泡排序、链表
- 还讲：
    - 动态规划
    - 贪心算法
    - 图算法
    - 高级树结构（红黑树、堆、 Trie树）

类比：初级只会走迷宫，高级会画迷宫地图、设计迷宫、找最短路径

### 设计思想：代码怎么组织高级
- 面向对象进阶（封装、继承、多态等）
- 设计思想（单例、策略、观察者、发布订阅、工厂）
- 架构思想（分层、解耦、高内聚低耦合）

类比：初级是搭积木，高级是盖楼（要考虑地基、承重、水电、以后能不能加层）

### 性能与底层：程序怎么跑的高级
- 多线程/并发
- 内存管理
- 编译与运行机制
- 时间与空间复杂度分析

类比：初始只会开车，高级需要懂发动机原理、油耗优化、甚至改造配件
